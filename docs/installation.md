# DroidLinux Installation Guide

## Prerequisites
- Android 7.0 or higher
- Termux app installed (from F-Droid recommended)
- Termux:X11 companion APK installed
- Minimum 3 GB free storage
- Minimum 2 GB RAM (4 GB+ recommended)

## Quick Start
Clone the repository and run the master installer:

```bash
git clone https://github.com/RamX571/DroidLinux-Android-PC.git
cd DroidLinux-Android-PC
bash install/install.sh
```

The installer executes 8 automated stages including system checks, Ubuntu setup, desktop configuration, and CLI installation.
