# DroidLinux CLI Command Reference

Manage your DroidLinux desktop environment using the `droidlinux` command:

| Command | Description |
|---------|-------------|
| `droidlinux start` | Starts Termux:X11 display server and launches XFCE desktop |
| `droidlinux stop` | Safely stops desktop and background sessions |
| `droidlinux restart` | Restarts the running desktop session |
| `droidlinux status` | Displays real-time RAM usage, process, and service status |
| `droidlinux update` | Checks and updates DroidLinux scripts |
| `droidlinux repair` | Fixes missing configurations and repairs broken package metadata |
| `droidlinux diagnostics` | Runs full hardware and environment diagnostics |
| `droidlinux benchmark` | Measures storage I/O and CPU performance |
| `droidlinux uninstall` | Safely uninstalls DroidLinux with confirmation |
